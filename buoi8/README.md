# Buổi 8 — Vòng đời Activity và lưu trạng thái

Sử dụng ứng dụng Dessert Clicker để tìm hiểu vòng đời Activity và quan sát các callback qua Logcat. Mỗi lần bấm vào món tráng miệng sẽ cập nhật số lượng đã bán và doanh thu; dùng rememberSaveable để giữ trạng thái khi xoay màn hình hoặc tạo lại Activity.
