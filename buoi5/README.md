# Buổi 5 — Xây dựng bố cục cơ bản

Thiết kế giao diện bằng Jetpack Compose qua năm bài: thiệp sinh nhật Birthday, trang bài viết Article, màn hình hoàn thành công việc Task Manager, bố cục bốn ô Quadrant và danh thiếp Business Card. Sử dụng Text, Image, Row, Column và Box để sắp xếp nội dung, căn chỉnh, tạo khoảng cách và định dạng giao diện.
